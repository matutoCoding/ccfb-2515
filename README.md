# 卡牌工艺预览系统

印厂卡牌订单的浏览器端工艺效果预览:镭射膜、烫金/烫银、局部 UV、击凸/压凹的实时三维渲染,用于打样前与客户确认效果。

## 启动

```bash
npm install
npm run dev      # 开发,默认 http://localhost:5173
npm run build    # 生产构建到 dist/
```

技术栈:React 18 + TypeScript + 原生 WebGL2(无 three.js)+ zustand(状态/持久化)+ jsPDF(印前导出)。

## 页面

| 页面 | 功能 |
|---|---|
| 订单列表 | 订单/卡面增删改,数据导出导入(JSON,含图片) |
| 卡面编辑 | 导入卡面图、拖动调整位置缩放、设置镭射膜厚 |
| 工艺图层 | 6 个工艺图层涂抹/擦除,笔刷可调,右侧实时三维效果 |
| 三维预览 | 轨道旋转/缩放,3 种环境光,导出 PNG 效果图和印前 PDF |
| 设置 | 卡面尺寸/厚度、默认环境光、渲染精度、数据管理 |

## 渲染设计(src/gl/shaders.ts)

- **镭射膜**:真·薄膜干涉——光程差 `2·n·d·cosθt` 对 380–700nm 光谱逐波长积分(CIE1931 高斯拟合 → XYZ → sRGB),不是贴渐变图;膜厚可调(300–700nm),颜色随视角连续变化
- **烫金/烫银**:金属环境反射 + 菲涅尔 + 程序化拉丝噪声扰动法线
- **局部 UV**:高光油(低粗糙度强高光)与哑膜基底对比
- **击凸/压凹**:蒙版高度图中心差分求法线,侧光下产生立体明暗
- **环境光**:摄影棚/窗边/射灯三种程序化环境,无需贴图

## 确定性保证(同角度两次渲染颜色一致)

- 着色器不含任何时间/随机 uniform,噪声全部是 uv 的哈希函数
- 关闭 MSAA、纹理不用 mipmap(mip 级别选择依赖 quad 导数,软光栅下有帧间不确定性),改用 renderScale 超采样抗锯齿
- 按需渲染(参数变化或拖动时才画帧),拖动流畅

## 数据

所有数据存浏览器 localStorage(`card-finish-preview-v1`),卡面图和工艺蒙版以 dataURL 内联,可整体导出/导入 JSON 备份。印前 PDF 含效果图、工艺清单和每个工艺图层的黑白工艺版(黑=工艺区域,红框=卡面轮廓)。
